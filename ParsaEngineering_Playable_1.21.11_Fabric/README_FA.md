# Parsa Engineering — مود کارخانه‌ای برای Minecraft 1.21.11

این پروژه سه بلوک قابل ساخت در Creative اضافه می‌کند:
- Industrial Generator
- Ore Crusher
- Electric Furnace

در این نسخه، بلوک‌ها قابل قرار دادن هستند و با راست‌کلیک پیام وضعیت نشان می‌دهند. **تولید برق، خردکردن واقعی سنگ معدن و ذوب خودکار هنوز پیاده‌سازی نشده‌اند**؛ این نسخهٔ اولیهٔ قابل گسترش است.

## ساخت فایل JAR بدون نصب ابزار توسعه روی کامپیوتر
1. ZIP را استخراج کن.
2. یک مخزن GitHub جدید بساز و فایل‌های داخل این پوشه را در آن آپلود کن.
3. تب Actions را باز کن و اجرای `Build Parsa Engineering` را انتخاب کن؛ اگر اجازه خواست، workflow را فعال کن.
4. وقتی سبز شد، صفحهٔ اجرای workflow را باز کن و از بخش Artifacts فایل `parsa-engineering-1.21.11` را دانلود کن.
5. ZIP خروجی را استخراج کن و JAR اصلی را در پوشهٔ `mods` پروفایل Fabric Minecraft 1.21.11 قرار بده. فایل `-sources.jar` را نصب نکن.

نیازمندی‌های توسعه: Minecraft 1.21.11، Fabric Loader 0.18.1، Fabric API 0.141.6+1.21.11 و Java 21.
